# بازبینی رابط کاربری

این گزارش به بررسی کد رابط و تطبیق آن با قراردادهای فعلی بک‌اند مربوط است. اجرای سناریوها در مرورگر و آزمون‌های بک‌اند، جداگانه توسط عامل اصلی انجام می‌شود؛ نتیجه آن‌ها را نباید از آزمون‌های واحد زیر استنتاج کرد.

## پوشش بخش‌ها

| حوزه | فهرست، جست‌وجو و جزئیات | فرم و عملیات |
|---|---|---|
| کارکنان و واحدها | پرونده، واحد و شناسه مرجع | ایجاد، ویرایش، وضعیت همکاری با تأیید دوم |
| قرارداد استخدام | مشخصات و دوره همکاری | ایجاد، ویرایش عنوان/پایان/یادداشت، خاتمه؛ قرارداد پایان‌یافته فقط خواندنی |
| مرخصی و مأموریت | درخواست‌ها و وضعیت | درخواست شخصی کارمند؛ تصمیم مدیر؛ تعیین فوق‌العاده هنگام تأیید مأموریت |
| تشویق و جریمه | سوابق و مبالغ | ایجاد؛ سابقه مالی حذف یا بازنویسی نمی‌شود |
| حقوق | مبنای حقوق، مزایا، کسورات، تعدیلات و خالص | صدور، اصلاح مزایا/کسورات پیش‌نویس، ثبت پرداخت با تأیید؛ پرداخت‌شده فقط خواندنی |
| کالا و تأمین‌کننده | اطلاعات و موجودی | ایجاد و ویرایش؛ نوع رهگیری در رابط پس از ثبت تغییر نمی‌کند |
| خرید | وضعیت و مبالغ | ثبت، تأیید، دریافت با سریال‌های لازم، لغو |
| گردش انبار | گردش و فیلتر ورود/خروج | ثبت؛ خروج سریال‌دار از مسیر تحویل انجام می‌شود |
| اموال | سریال و فیلتر وضعیت | ثبت، اصلاح توضیح، اسقاط دارایی موجود؛ تحویل‌گرفته یا اسقاط‌شده تغییر وضعیت مستقیم ندارد |
| تحویل و بازگشت | گیرنده، تجهیز و فیلتر وضعیت | انتخاب یک نوع کالا/دارایی؛ ثبت تحویل؛ بازگشت یک‌باره با تأیید |
| گزارش موجودی | کل، قابل تحویل و حداقل؛ فیلتر کم‌موجودی | فقط خواندنی و CSV |
| مشتری و خدمات | ارتباطات، قیمت و وضعیت | ایجاد و ویرایش؛ مراجع غیرفعال برای عملیات جدید انتخاب نمی‌شوند |
| پیشنهاد قیمت | مشتری، ردیف‌ها، جمع و وضعیت | ایجاد، اصلاح پیش‌نویس با حفظ ردیف‌ها، ثبت ارسال، پذیرش یا رد؛ سایر وضعیت‌ها قابل ویرایش نیستند |
| قرارداد پروژه | مشتری، مسئول، مبلغ و وضعیت | ایجاد مستقل یا از پیشنهاد پذیرفته‌شده؛ ویرایش محدود بر اساس وضعیت؛ فعال‌سازی، تکمیل و لغو |
| صورتحساب | مبلغ، مانده، سررسید و وضعیت | صدور در محدوده مانده قرارداد؛ ابطال صورتحساب پرداخت‌نشده با تأیید |
| دریافت | مشتری، قرارداد، روش و پیگیری | ثبت مبلغ مثبت برای صورتحساب دارای مانده؛ سوابق مالی فقط خواندنی |
| مطالبات | مشتری، قرارداد، سررسید و مانده | فقط خواندنی و CSV |
| حساب و مدیریت | ورود، خروج، مشخصات، کاربران و رویدادها | تغییر گذرواژه و ورود دوباره؛ کاربران فقط مدیر سامانه؛ رویدادها مدیر و مدیر سامانه |

## اصلاح‌های قابل بازتولید

- خطای ۴۰۱ به سامانه و توکن مبدأ متصل شد تا پاسخ قدیمی، نشست ورود جدید را باطل نکند.
- پاسخ جست‌وجوی قبلی و دریافت گزینه‌های فرم پس از خروج از صفحه لغو می‌شوند.
- CSV تا پایان تأخیر جست‌وجو غیرفعال است؛ فیلتر در همه صفحات دریافت حفظ می‌شود. عبور از سقف دریافت، خطای صریح دارد و فایل ناقص به‌عنوان خروجی کامل تحویل داده نمی‌شود.
- مقادیر عددی قبل از تبدیل JSON، صحیح و امن بودن بررسی می‌شوند؛ داده‌های nullable و فیلدهای بدون تغییر در PATCH به‌درستی مدیریت می‌شوند.
- رمز عبور فاصله‌های ابتدا و انتها را حفظ می‌کند. عدم دسترسی مرورگر به sessionStorage مانع ورود در همان زبانه نمی‌شود.
- ویرایش روابط تاریخی، گزینه غیرفعال فعلی را حفظ می‌کند؛ ایجاد رابطه جدید به موارد مجاز محدود است.
- تاریخ بدون ساعت، در منطقه زمانی دیگر یک روز جابه‌جا نمی‌شود. رویدادهای ممیزی، ساعت و دقیقه نیز دارند.
- جزئیات فیش حقوق، تشویقی، جریمه و فوق‌العاده دوره را نشان می‌دهد. سریال‌های گردش نیز خوانا نمایش داده می‌شوند.
- هنگام نوشتن در سرور، Escape، پس‌زمینه و بستن پنجره نمی‌توانند فرم را ببندند. ارسال هم‌زمان تکراری در فرم ثبت و عملیات محافظت شده است.
- منوی بسته موبایل از ترتیب فوکوس خارج است؛ منوی باز، فوکوس محدود و Escape دارد. پس‌زمینه آن تعاملی نیست.
- کنترل‌های موبایل حداقل ۴۴ پیکسل‌اند. متن کم‌رنگ نامناسب روی سطوح روشن تیره‌تر شده است؛ برای نمونه نسبت ۳٫۰۸ به حداقل ۴٫۷۳ برای متن خنثی اصلی اصلاح شده است. این اندازه‌گیری محدود، ادعای گواهی جامع WCAG نیست.

## بررسی خودکار

`npm test` شامل ۱۶ آزمون رگرسیون برای مجوز درخواست شخصی، فیلدهای تغییرپذیر، اصلاح حقوق و پیشنهاد، حفظ خطوط پیشنهاد، عدد امن، null، رمز دارای فاصله، انتخاب مراجع، گذار وضعیت، CSV، منطقه زمانی، صفحه‌بندی خروجی، مبدأ خطای نشست و storage مسدود است.

دستورهای مستقل:

```powershell
npm test
npm run typecheck
npm run format:check
npm run build
```

پوشش خودکار مرورگر در این گزارش ادعا نمی‌شود. تعامل واقعی با انتخاب‌گر تاریخ بومی، دانلود فایل مرورگر، فناوری‌های کمکی و دستگاه لمسی فیزیکی، به بررسی محیط اجرا نیاز دارد. CSV چندصفحه‌ای، تصویر تراکنشی یک لحظه از دیتابیس نیست؛ تغییر هم‌زمان داده‌ها هنگام دریافت می‌تواند ترتیب صفحات را تغییر دهد.
