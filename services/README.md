# سه سامانه مستقل رویش

| پوشه | سامانه | مسئولیت |
| --- | --- | --- |
| [personnel](personnel/README.md) | پرسنلی | کارکنان، استخدام، مرخصی، مأموریت و حقوق |
| [inventory](inventory/README.md) | انبار | کالا، خرید، موجودی، اموال، تحویل و بازگشت |
| [commerce](commerce/README.md) | بازرگانی | مشتری، خدمات، پیشنهاد، قرارداد، صورتحساب و مطالبات |

هر پوشه کد بک‌اند و راهنمای اختصاصی همان سامانه را دارد. اجرای `start.cmd` داخل آن پوشه، فقط همان API و رابط را شروع می‌کند؛ نصب اولیه از ریشه با `setup.cmd` انجام می‌شود. سه پایگاه داده و سه ورود مستقل‌اند.

کد پایه در [shared](../shared) و رابط قابل بازاستفاده در [frontend](../frontend/README.md) است. [README اصلی](../README.md) مسیر نصب و اجرای همه سامانه‌ها را توضیح می‌دهد.
